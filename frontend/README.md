# MyFastHR — Frontend React Application

This directory contains the React frontend code for the MyFastHR platform.

## 🛠️ Tech Stack & Structure
* **Build Tool**: Vite
* **Library**: React 19
* **Styling**: Tailwind CSS & custom responsive CSS stylesheets
* **Icons**: Lucide Icons
* **Charts**: Recharts

## ⚡ Development Setup
Ensure you have the backend running first, then run:
```bash
npm install
npm run dev
```

For general architecture, deployment scripts, and database setup, please refer to the global **[README.md](../README.md)** file in the project root.
